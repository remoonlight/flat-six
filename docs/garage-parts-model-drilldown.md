## 交互摘要（说人话）

1. 「模型」列表先列大系统（水冷/燃油/…）。
2. 点水冷 → 展开水冷子 mesh，其它收起；左边切透视并高亮水冷。
3. 点子 mesh → 展开 OEM 号/价 + 副厂价；点 **关联** → 弹窗填 OEM → 保存；列表上显示 OEM 指针。
4. 外观/内饰点叶子 → 同样先展开看价，再关联绑 OEM。
