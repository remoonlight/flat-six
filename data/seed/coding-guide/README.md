# 981 社区设码参考

来源：[StormEye818/porsche-coding-guide-tool](https://github.com/StormEye818/porsche-coding-guide-tool)，固定提交 `a1f5af3bdd1b0ac78becd94033cd4ebf9df9de7b`，获取日期 2026-09-13。按 MIT 许可保留版权与许可证，见 `LICENSE-StormEye818.txt`；桌面应用的来源说明中也包含该许可。

`981.json` 从来源 `ITEMS` 数据中筛选 `compat` 包含 `981` 的项目，并再次筛选各步骤的 `compat`。本版本为 **64 项、129 步**。保留源 ID、名称、中英文路径、备注及来源参考值，不收录其他车型专用项目；不执行上游网页代码。

导入命令：`npm run ingest:coding-guide -- <参考仓库的本机路径>`。导入器只解析静态数据字面量，固定来源提交；更新来源时先审查差异再更改固定提交。

车型使用规则：

- 产品固定为 2014 Boxster S（981）PDK。上游只按系列过滤，不能由此推导每条均适合本车年款或 ECU。
- 来源的 `compatStatus=ok` 保留为来源元数据；界面显示“社区参考 · 待实车核对”，不转成“本车已验证”。
- 涡轮压力项目 #5 不适用当前自然吸气车辆，默认隐藏，开启“不适用条目”后可查阅但不能加入方案。默认显示 63 项候选。
- 记忆座椅、电动折叠后视镜、时钟、雨量传感器等显示具体硬件条件；#13 年款可用性待核对，#602 来源原值含 982，不能当成本车转向参数。
- #301 / #302 二选一；#9002 的按键布局 A / B 二选一；#11 / #103 为日行灯配套项。
- 步骤明确写出车门或附加时钟 ECU 的，方案和实测记录按步骤路径的 ECU 分组，保留原功能分类和原路径。

当前实现是对照指引和本机快照记录，不包含 CAN 写入载荷、编码位定义、安全访问或自动写车接口。参考值不会自动填入实测值字段。新旧记录均保存在原 SQLite `coding_snapshots`，原 X431 种子及记录未迁移、未替换。

功能勾选和按键方案属于当前页面会话，离开实时 OBD 或退出应用后需重新选择；需要保留的方案可复制为文本。实际操作记录长期保存在 SQLite。

验证：`npm test`、`npm run accept:coding-guide-ui`。UI 验收用独立临时数据库，涵盖车型筛选、跨模块步骤、替代方案、复制、原值留空、原 X431 入口以及重启后的记录回读。
